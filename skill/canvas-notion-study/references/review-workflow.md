# 重点提取与质量核对

先阅读 review-packet 中的实际资料，再生成 enrichment。原文变化后重新核对；为 enrichment 保存对应来源内容的 hash 或更新时间。对多个同名大纲，核对课程、学期和发布日期，不能直接取文件名相似的旧版本。

大纲按实际存在的内容提取：教师与助教、联系渠道、office hours、考核构成和权重、考试与作业日期、迟交/缺交规则、教材与软件要求、上课和实验安排、材料中明示的其他课程要求。每条关键结论附源文件与页码或源页面。扫描件或表格提取质量低时用宿主的文档工具阅读原件并检查页面；失败时标为待核实。

通知保留发布时间、标题、简明摘要、原文链接，提取明确的个人行动项。建议阅读与必须完成区分。行动项提供原句、来源 ID、可确定的日期与时区；“下周五”以通知发布时间为参照，歧义保留待核实。通知引用已有作业时附实际 assignment_id，关联而不重复建任务。

公告任务的语义 ID 需可重用，不能按每次模型改写后的标题生成；沿用上次 enrichment 的 action ID。当源通知变更时，通过原始行动及上下文匹配既有 ID，新增内容再给新 ID。

课堂 PPT、讲义和作业附件原样留存。不要擅自把整套讲义自动变成课程笔记。Notes 为学生提供独立笔记入口。Calendar events、明确课程时间及用户课表可进入 Timetable，来源不全时说明范围，不能假设完整。

模型没有阅读的资料保持 pending，不能用文件名或正文首段装作完成摘要。用户要求完成当前资料整理时，要继续读完所选范围并填充摘要；只有确实不可访问或无法辨认的内容才作为有证据的限制保留。
